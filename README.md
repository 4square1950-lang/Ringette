# Ringette · Northern Circuit

A 3D ringette game with single player, same-keyboard multiplayer, training, a ten-city circuit, and a local four-club cup.

## Start the game

```sh
npm install
npm start
```

Open [the local game](http://localhost:4198/). Play and progress are stored on this browser. The market uses local game coins.

## Controls

- **Player 1** · WASD to skate, mouse to aim, E to pass or stick-check, Space to shoot, and Q to switch skaters. Left click also shoots and right click passes or checks.
- **Player 2** · Arrow keys to skate, O to pass or stick-check, Enter to shoot, and U to switch skaters.
- **Escape** pauses the match.

The game models five skaters and a goalie per side, individual blue-line passes, the goalie-only crease, a free-play-line cap, and a 30-second possession clock. Match length is selectable. This build uses simplified restarts and does not include online rooms.

Rules reference [Ringette Canada](https://www.ringette.ca/kids/how-to-play-ringette/).
